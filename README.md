# Screen Overlay Translator (Windows)

Высокопроизводительное десктопное приложение для Windows, выполняющее синхронное оптическое распознавание текста на экране (Screen OCR) и выводящее перевод в виде сквозного оверлея поверх исходных блоков текста в реальном времени.

Разработано для перевода интерфейсов, диалогов, подсказок и логов в любых приложениях и компьютерных играх (Dota 2, CS2, RPG и др.) без переключения окон.

---

## Архитектура и возможности

### 1. Сквозной кликабельный оверлей (Click-Through Overlay)
* Оверлей использует системные флаги Win32 `WS_EX_TRANSPARENT | WS_EX_LAYERED`.
* Окно полностью прозрачно для событий мыши: все клики, движения курсора и драг-н-дроп беспрепятственно проходят в нижележащее приложение или игру.
* Переведенный текст выводится на контрастных полупрозрачных темных плашках с белым антиалиасным шрифтом точно над оригинальным текстом.

### 2. Локальный движок RapidOCR (ONNX Runtime)
* Высокая скорость захвата экрана через библиотеку `mss` и локального инференса нейросетей RapidOCR без передачи скриншотов на сторонние серверы.
* Полная конфиденциальность: данные не покидают компьютер пользователя.
* Низкая задержка: разовый инференс занимает доли секунды.

### 3. Интеллектуальный дифференциальный хэш кадров
* Перед запуском OCR вычисляется быстрый перцептивный хэш захваченного изображения.
* Если изображение на экране не изменилось со времени предыдущей проверки, распознавание пропускается, обеспечивая 0% загрузки CPU в режиме автосканирования.

### 4. Фильтрация по исходному языку
* Распознанный текст фильтруется в соответствии с выбранным исходным языком (`source_lang`).
* Например, при выборе английского языка переводится только латиница, а элементы интерфейса на других языках игнорируются.
* Поддерживается более 45 языков (русский, английский, немецкий, французский, испанский, китайский, японский, корейский, арабский и др.).

### 5. Интерактивный селектор зоны экрана
* Инструмент выделения произвольной прямоугольной области экрана (в стиле Snipping Tool).
* Позволяет ограничить мониторинг конкретным окном (например, чатом, инвентарем или субтитрами), снижая нагрузку на систему.

## Горячие клавиши

| Сочетание клавиш | Действие |
| --- | --- |
| Ctrl + Alt + S | Моментальный снимок экрана и перевод текста оверлеем |
| Ctrl + Alt + Z | Интерактивный выбор прямоугольной зоны экрана |
| Ctrl + Alt + O | Включение / выключение циклического автосканирования |
| Esc | Отмена выбора зоны экрана |

---

## Требования к системе

* Windows 10 / 11 (x64)
* Python 3.10 или новее
* Режим игры: «В окне без рамки» (Borderless Window) для отображения поверх игр

---

## Установка и запуск

1. Перейдите в каталог проекта:
```bash
cd screen-overlay-translator
```

2. Установите зависимости:
```bash
pip install -r requirements.txt
```

3. Запустите приложение:
```bash
python main.py
```

Приложение свернется в системный трей Windows.
* Нажмите **Ctrl + Alt + S** для мгновенного снимка и перевода текста на экране.
* Нажмите **Ctrl + Alt + Z** для ограничения области перевода.
* Нажмите **Ctrl + Alt + O** для автоматического обновления перевода.
* Правый клик по иконке в трее открывает меню управления и настройки.
